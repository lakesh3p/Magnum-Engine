# Sprites, 2D games and decals

## Sprites

A **Sprite** is a flat picture in the world. Add one from Place Actors → 2D, or drag an image from the Content Browser onto
the *Texture* field of a Sprite.

| Field | Meaning |
|---|---|
| Texture | project path of a PNG / JPG / TGA / BMP |
| Tint, Opacity | color multiplied into the picture; transparency |
| Width, Height | world size; both 0 = the picture's size divided by *Pixels per unit*; one given keeps the proportions |
| Pixels per unit | 100 by default; 16 for 16-pixel art that should be one unit per tile |
| Columns, Rows, Frame | the picture is a grid of cells; *Frame* picks one (counted from the top left, row by row) |
| First frame, Frame count, FPS, Animate, Loop | play cells as an animation |
| Flip X / Y, Billboard, Pixelated | mirror; always face the camera; crisp nearest-neighbour sampling |
| Order | higher draws in front; sprites with the same order are sorted by depth |

Sprites blend with what is behind them, are hidden by solid meshes in front of them, and never hide each other (that is what
*Order* is for). The pipeline pass is `{ "sprites" }`.

In scripts:

```lua
self.sprite.flip_x = true
self.sprite:play(2, 5, 12)            -- cells 2..5 at 12 frames per second (looping; a 4th argument false plays once)
self.sprite.tint = vec3(1, 0.5, 0.5)
world.spawn_sprite("Content/Textures/coin.png", x, y, width, height, "Coin")
```

## 2D games

* **Camera 2D** (Place Actors → 2D) is a Camera with *Orthographic* on; *Ortho size* is half the height of the view in world units.
* **2D view**: the `3D / 2D` button in the viewport switches to a flat view: right or middle drag pans, the wheel zooms around the mouse,
  F focuses the selection, new actors go to the middle of the view. Console: `view 2d`.
* **2D physics**: *Physics Sprite*, *Tile* and *Player 2D* have a Collider sized from the sprite, and a Rigidbody with *Lock Z*, which
  keeps the body on its plane. Everything else (gravity, ground, triggers, `on_hit`) is the normal physics.
* **Mouse in the world**: `input.mouse_world([z])` is the point on the plane `z` under the mouse, `input.mouse_position()` the position over
  the view (0..1). With an orthographic camera it is exactly where you point.
* A 2D pipeline needs no sky or meshes: `clear` + `sprites` (see `Projects/Platformer2D/Content/Pipelines/default.lua`).

`Projects/Platformer2D` is a complete small game: pixel-art sprites with animation, tiles, coins, patrolling slimes, a goal,
a camera that follows, a main menu, a pause menu and a HUD.

## Decals

A **Decal** projects a picture onto whatever solid surface is inside its box: bullet holes, blood, a sign on a wall, a rune on the floor.
The box is the actor's transform: the picture goes along the actor's local Z axis (a new Decal points down) and fills local X / Y,
so *Scale* is width, height and how deep the projection reaches.

| Field | Meaning |
|---|---|
| Texture, Tint, Opacity | the picture |
| Angle fade | fades the decal out on surfaces seen edge-on, where it would smear |
| Material | optional: a material whose shader was written for decals, to animate or generate the picture |
| Order | higher draws later |

The pipeline pass is `{ "decals" }` (after `meshes`). It reads the depth of what was drawn so far, so decals work on any mesh.

From a script, `world.spawn_decal("Content/Textures/decal_bullet.png", hit.point, hit.normal, 0.5)` puts one on whatever a
`world.raycast` hit.

Writing a decal shader: see `Engine/Shaders/decal.lua`. The shader DSL has `scene_depth`, `inv_model`, `inv_view_proj` and `frag_coord`
for it; the shader receives the surface point in the decal's own space (-0.5 .. 0.5 on every axis).
